Quantway для Windows

Выберите установщик для своей архитектуры: amd64 — Intel/AMD x86_64,
arm64 — Windows на ARM. ARM64 требует Windows 11; x86_64 — Windows 10 или новее.
GTK, Python, tinc и подписанный драйвер Wintun включены в установщик:
отдельно устанавливать Python или компиляторы не требуется.

Запустите Quantway Setup, подтвердите установку, затем откройте Quantway
из меню Пуск обычным пользователем. При подключении VPN появляется запрос
Windows на права администратора для сетевого помощника.

Перед обновлением или удалением отключите VPN и закройте приложение.
Удаление доступно через «Установленные приложения» Windows.
Данные аккаунта и ключ устройства сохраняются отдельно от программы.

Этот выпуск — предварительная сборка. Само приложение и установщик
пока не имеют сертификата Authenticode. Wintun поставляется в исходном
подписанном виде из официального дистрибутива wintun.net.

Лицензии зависимостей и соответствующие исходники tinc находятся в licenses/;
дополнительные лицензии GTK/Python — в runtime/share/licenses/.
